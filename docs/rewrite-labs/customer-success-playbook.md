# Rewrite Labs Customer Success Playbook

Onboarding, Retention, Expansion

---

## **1. Customer Journey**

### **Stage 1 — Activation**
- Customer submits first URL  
- Receives redesign preview  
- Approves variant  

### **Stage 2 — Adoption**
- Uses outreach automation  
- Reviews analytics  
- Deploys redesign  

### **Stage 3 — Expansion**
- Adds more URLs  
- Upgrades plan  
- Adds team members  

---

## **2. Success Metrics**
- Redesign approval rate  
- Outreach engagement  
- Conversion uplift  
- Monthly active redesigns  
- Customer satisfaction  

---

## **3. Onboarding Checklist**
- Account setup  
- First redesign  
- Outreach configuration  
- Analytics walkthrough  
- Success plan creation  

---

## **4. Quarterly Business Review (QBR)**
- Review redesign performance  
- Review outreach results  
- Identify new opportunities  
- Recommend upgrades  

---

## **5. Renewal Playbook**
- 90‑day check‑in  
- Value recap  
- ROI summary  
- Renewal proposal  

---

## **6. Expansion Playbook**
- Add more redesign volume  
- Add team seats  
- Add white‑label  
- Add API access  

---

## **7. Support Escalation**
- Tier 1: Operator support  
- Tier 2: Engineering  
- Tier 3: CIC governance
